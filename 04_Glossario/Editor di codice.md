# Editor di codice

Un programma per scrivere Testo semplice, pensato per il [Codice](Codice.md): colora le parole secondo il loro ruolo, segnala gli errori più evidenti, tiene in ordine i file di un progetto. Non è un programma di videoscrittura: non impagina e non aggiunge formattazione. Nel corso usiamo Visual Studio Code.
