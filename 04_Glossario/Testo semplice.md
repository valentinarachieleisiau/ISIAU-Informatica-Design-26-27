# Testo semplice

Un file che contiene solo caratteri, senza formattazione nascosta. Si apre con qualunque programma, su qualunque computer. Un documento Word, invece, è un pacchetto complesso che solo certi programmi sanno leggere. Tutto il codice che scriviamo nel corso è testo semplice.
