# Estensione

La parte finale del nome di un file, dopo il punto: `.txt`, `.html`, `.jpg`, `.pdf`. Dice al computer che tipo di file è e con quale programma aprirlo. Cambiare l'estensione non cambia il contenuto del file: cambia chi prova a leggerlo.

In Visual Studio Code la stessa parola ha un secondo significato: un piccolo programma che si installa dentro l'editor e gli aggiunge una funzione, come un *plug-in* in Photoshop o in InDesign. Si cercano e si installano dalla colonna di sinistra, nel riquadro *Extensions* (*Estensioni*).
