# Modello di sketch

La cartella da cui nasce ogni sketch nuovo. Su Classroom la trovate dentro il file compresso della lezione, con un nome che dice a che cosa serve: nella L03 si chiamava `composizione`. Contiene tre cose:

- `index.html`: la pagina che aprite nel browser. Non si tocca
- `sketch.js`: il vostro codice. È l'unico file che modificate
- `lib/p5.min.js`: la libreria p5.js, versione 2.3.4. Non si tocca

## Come si usa

1. Scaricate il file compresso da Classroom ed estraetelo dentro la vostra cartella `esercizi`
2. Aprite la cartella del corso in Visual Studio Code, e lì aprite `sketch.js`
3. Aprite `index.html` in Chrome: clic destro sul file → **Apri con** → **Google Chrome**. Con il doppio clic, sul Mac, si apre Safari
4. Ogni volta che cambiate il codice: salvate in Visual Studio Code (`Cmd + S`), poi ricaricate la pagina in Chrome (`Cmd + R`). Su Windows: `Ctrl + S` e `Ctrl + R`

È lo stesso gesto di `prova.html`: si salva, si ricarica.
