# Modello di sketch

La cartella da copiare ogni volta che cominciate uno sketch nuovo. Contiene tre cose:

- `index.html`: la pagina che aprite nel browser. Non si tocca
- `sketch.js`: il vostro codice. È l'unico file che modificate
- `lib/p5.min.js`: la libreria p5.js, versione 2.3.4. Non si tocca

## Come si usa

1. Copiate la cartella `modello-sketch` dentro la cartella del corso, e rinominatela con un nome che dice che cos'è, senza spazi: per esempio `L03-composizione`
2. Aprite la cartella del corso in Visual Studio Code, e lì aprite `sketch.js`
3. Aprite `index.html` nel browser, con un doppio clic
4. Ogni volta che cambiate il codice: salvate in Visual Studio Code, poi ricaricate la pagina nel browser

È lo stesso gesto di `prova.html`: si salva, si ricarica.
